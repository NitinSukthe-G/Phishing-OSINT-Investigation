# Screenshot Evidence

Upload your actual investigation screenshots to this folder.

Recommended filenames:

```text
01-email-header-analysis.png
02-url-extraction.png
03-dns-whois-results.png
04-virustotal-search.png
```

Before uploading, ensure screenshots do not expose:

- Passwords
- API keys
- Access tokens
- Browser cookies
- Private email addresses
- Personal account information

Do not create fake screenshots. Use only evidence captured during your own lawful investigation.
